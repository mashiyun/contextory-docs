# PoC

技術選定前に実機確認が必要な項目を管理します。

## 候補

- SwiftUI `MenuBarExtra`、グローバルショートカット、終了処理。
- macOSの範囲キャプチャ。
- システム音声とマイクの同時録音。
- 画面録画とファイルサイズ・CPU・メモリ負荷。
- Claude Codeへ画像とMarkdownを限定して渡す処理。
- 取得完了から要約Markdown生成までの処理時間。
- 複数Sourceの案件・タスク候補への自動グルーピング精度。
- 個人情報・秘密情報のローカル検出とマスク。
- Markdown／ファイルVaultの検索性能。
- Source BundleからSQLite Indexを再構築できること。
- 原本保存後にSQLite更新が失敗しても再処理できること。
- ManifestとSQLiteの不整合を検出・修復できること。
- Claude Code自動処理の認証切れ、タイムアウト、不正出力、手動再実行。
- 自動グルーピング候補を手動修正し、再分析で上書きされないこと。
- 私用MacでRelease `.app`を作成し、会社Macへバイナリだけを提供して起動できること。
- Gatekeeper初回起動、画面収録・マイク権限、更新版への置き換えを確認すること。
- 直接配布が安定しない場合、会社MacでXcodeローカルビルドして起動できること。

## 最初の縦切りPoC

### Phase 0: 配布・権限スパイク

1. 空のmacOSメニューバーアプリをReleaseビルドする。
2. 署名、entitlements、同梱内容、SHA-256を確認する。
3. 会社Macへ`.app`だけを提供し、Gatekeeper経由で起動する。
4. 最小の画面収録・マイク権限要求が通ることを確認する。
5. Claude Codeのパスと認証状態を確認する。
6. 更新版へ置き換え、起動、権限、アプリデータの維持を確認する。
7. 直接配布が安定しない場合だけ会社Macでローカルビルドする。

### Phase 1以降: CaptureからAI処理まで

1. macOSメニューバーから範囲キャプチャを開始する。
2. Source Bundleへ原本とManifestを保存する。
3. SQLite IndexへSourceを登録する。
4. Claude Codeを非対話実行して構造化結果を取得する。
5. `summary.md`を生成して処理状態を完了にする。
6. 失敗状態を表示し、手動再実行できることを確認する。

試験結果は実施済み、進行中、未実施を分けて記録します。
